- .NET：Microsoft，MIT 许可；自包含发布中的第三方声明见 `ThirdPartyNotices.txt`。
- Windows App SDK / WinUI 3：Microsoft，采用各 NuGet 包中的许可与第三方声明（MIT / Microsoft 组件相关条款）。
- CommunityToolkit.Mvvm：.NET Foundation，MIT 许可。
- System.Security.Cryptography.ProtectedData：Microsoft，MIT 许可。
- Inno Setup：Jordan Russell / Martijn Laan，构建安装包使用，许可见 https://jrsoftware.org/files/is/license.txt 。

WinUI 图标来自 Windows 原生字体，跟随系统使用，不单独复制系统字体。程序不包含代理内核、真实订阅或服务商配置。
